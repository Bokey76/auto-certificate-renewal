# 目标

单机签发、续签，以及应用到宝塔 Nginx、自装 Nginx、阿里云 CDN，已经可以按 [README.md](../README.md) 使用。本机状态网页也已经可以按 [使用.md](使用.md) 打开。本文只保留还没有做的事。

## 控制机

把多台已经装好本程序的机器汇总到一台控制机。各机数据卷里的 `status.json` 仍是数据来源。本机标识用配置里的 `serverName`，省略时用主机名。

还没有做的是：一台控制机同时看到多台机器，以及在网页上修改并下发各机的任务配置。协议还没定。

各机仍由本机容器执行 `nginx -t` 和 reload。控制机不进入其他机器的命名空间。控制机停机时，各机继续按上一份本地配置工作。

## 通知

还没有通知渠道。签发失败、Nginx 重载失败或 CDN 绑定失败时，到本机日志和 `status.json` 里查看。

## 多台源站共用一张证书

还不能在机器之间拷贝证书，也没有「只应用、不签发」的任务。同一张证书要给多台源站用时，目前在其中一台机器上签发。
