# 目标

单机签发、续签，以及应用到宝塔 Nginx、自装 Nginx、阿里云 CDN，已经可以按 [README.md](../README.md) 使用。本文只保留还没有做的事。

## 控制机和网页

加一台控制机，管理多台已经装好本程序的机器。各机数据卷里的 `status.json` 是它的数据来源。本机标识用配置里的 `serverName`，省略时用主机名。

控制机提供网页，用来：

- 看到每台机器是否在线、最近一轮何时跑完、退出码是什么
- 看到每张证书的域名、到期时间、签发结果、CDN 是否绑定成功
- 看到每台机器上 Nginx 动作的测试和 reload 结果
- 查看、修改下发到各机的任务配置
- 查看每台机器的运行日志

各机仍由本机容器执行 `nginx -t` 和 reload。控制机不进入其他机器的命名空间。配置下发和日志查看的协议还没定。控制机停机时，各机继续按上一份本地配置工作。

## 通知

还没有通知渠道。签发失败、Nginx 重载失败或 CDN 绑定失败时，到本机日志和 `status.json` 里查看。

## 多台源站共用一张证书

还不能在机器之间拷贝证书，也没有「只应用、不签发」的任务。同一张证书要给多台源站用时，目前在其中一台机器上签发。
