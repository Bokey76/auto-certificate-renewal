# 项目说明

给后续改代码、写文档时用。用法见仓库根目录 [README.md](../README.md)。规则见 [AGENTS.md](../AGENTS.md)。

## 这是什么

公开开源的自动续签工具。每台 Linux 服务器跑同一个 Docker 镜像、自己的一份 YAML。用 Let’s Encrypt（Certbot）签发证书，应用到：

- 宝塔 Nginx 或自装 Nginx（只换 pem，再 `nginx -t` / reload）
- 阿里云 CDN 内容分发（先上传 CAS，再按 CertId 绑定）

校验按任务选 HTTP-01 或 DNS-01。DNS-01 只对接阿里云云解析。泛域名必须 DNS-01。

当前没有网页、没有控制机、不发通知，也不在机器之间拷贝证书。这些见 [目标.md](目标.md)。没要求就不要做。

## 怎么跑

开发机构建镜像，推到操作者自己的容器镜像服务；服务器只放三份本地文件：`docker-compose.yml`、`config/config.yaml`、`.env`。步骤见 [使用.md](使用.md)。

容器默认 `cert-renew schedule`：起来先跑一轮，再按 `TZ` + `schedule.hours` 检查，每次现抽 0–30 分钟偏移。

一轮里根据到期时间和上次应用成败，决定跳过、签发、或只重试 Nginx/CDN。过程见 [执行流程.md](执行流程.md)。

## 目录

| 路径 | 作用 |
| --- | --- |
| `src/` | TypeScript 编排。入口 `cli.ts`，任务流 `runner.ts` |
| `config/config.example.yaml` | 提交到仓库的配置模板 |
| `config/config.yaml` | 本机真实配置，gitignore |
| `.env.example` / `.env` | 密钥模板 / 真实密钥 |
| `Dockerfile` / `docker-compose.yml` | 镜像与本机构建用的 compose 示例 |
| `docs/` | 配置、部署、执行过程和源码说明 |
| `docs/目标.md` | 还没有做的事 |
| `README.md` | 使用者入口 |
| `AGENTS.md` | 给后续实现和文档的约束 |

容器内：配置 `/config/config.yaml`，数据卷 `/var/lib/acme`（证书、state、status、日志）。

## 已定约束

- Node.js `>=24.22.1`，镜像基础 `node:24.22.1-bookworm`
- 不自己实现 ACME，只调 Certbot CLI
- 不改 Nginx server 块，不写宝塔数据库
- CDN 只做内容分发，不做 DCDN / ESA
- 不删除 CAS 旧证书，不创建 CDN 域名
- 任务串行；一条失败其它继续
- `pid: host` + `privileged` 只为 `nsenter` 调宿主机 nginx
- 测试不访问 Let’s Encrypt 和阿里云：`npm test`

## 开源红线

本仓库是公开的。真实密钥、真实域名、真实镜像仓库地址、个人邮箱、服务器 IP **不能**出现在会提交的文件里。占位符用 `example.com`、`ops@example.com`、`<ACR域名>`。真实值只放 gitignore 的 `.env` 和 `config/config.yaml`，以及服务器上不入库的 compose。

完整条款在 [AGENTS.md](../AGENTS.md)。
